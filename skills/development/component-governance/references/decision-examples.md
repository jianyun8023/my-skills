# 决策示例与来源

按遇到的问题读取对应示例。这些是对项目经验的概括，不要求使用相同框架、目录或类名，也不要求访问原项目。

## 异步筛选：复用交互，业务提供候选

用量筛选与事件类型筛选都有按需加载、输入防抖、取消和重试，可以共用接收 `loadOptions(search, signal)` 的展示组件。端点、时间范围及鉴权上下文由调用方提供，组件不导入具体业务客户端。

复用前检查候选的语义和生命周期是否一致；身份或查询范围变化后不显示旧候选，即使已取消的请求迟到也不能提交。筛选草稿和最终业务查询仍各有所有者。仅仅都是下拉菜单，并不足以把静态枚举也接入异步加载机制。

## 异步读取：先核实竞态，再匹配共享机制

手动刷新和定时轮询各自维护请求，看起来适合共用查询 hook。先检查相关调用路径：父级是否按身份重新挂载、读取是否可能重叠、响应如何排序、交互期间是否暂停提交。有父级保护时，不把子组件没有重置代码直接判为身份泄漏；保护仍有缺口时，给出具体触发顺序，而非仅凭多个 effect 断言有 bug。

例如，一次轮询先发出但较晚返回，覆盖操作后刷新得到的新结果；若没有序号、取消或其他提交保护，这就是需要处理的竞态。可以先在领域内统一读取和提交保护。

已有 helper 即使处理了取消，也未必满足调用方契约：调用方可能在 `await refresh()` 后再推进选中项，helper 的 `reload()` 却只发出重载信号；调用方还可能在冲突编辑期间冻结提交。复用前核对这些差异，选择局部实现、小幅适配或值得投入的扩展。领域交互策略继续由领域拥有，不把修复竞态自动升级为通用 hook 改造。

## 虚拟列表：布局机制与领域分页分开

通用网格组合框架已有虚拟列表，接收项目渲染方式并暴露可见范围/触底事件。书库等领域拥有查询游标、身份去重、缓存键、加载状态和重试，业务层将视口需求转成数据请求。

不让通用网格知道书籍、数据库或具体服务器；也不将虚拟列表重新实现一遍，只为适配预想的跨框架 API。只有状态可以独立消费或生命周期需要独立管理时，才继续拆 controller/hook。

## 共享状态放在某个视图内：评估搬迁的净收益

列表、网格和详情都通过表格适配器访问同一模型，说明其他视图与表格内部结构耦合；它本身不证明状态重复、行为错误或依赖规则被违反。

先检查实际消费者、更新入口、观察订阅和销毁时机。比较保留所有者并收窄访问接口、搬到现有领域所有者、建立独立状态实体的收益与成本。独立实体只有在解开现有消费或生命周期耦合时才有价值，同时会增加订阅、通知和状态协调责任；不要仅因名字叫 Table 就要求新建 store。

## 原生控件与组件变体：只封装有意义的差异

可选日期编辑不仅是一个日期控件，还包含设置、清除和未设置状态；统一封装有明确价值。普通按钮或文字框可以直接组合系统控件，由共同主题入口提供样式，无需每种控件都增加代理组件。

若一个编辑器不断增加 `isThread`、`isForwarding` 等互斥业务模式，考虑显式变体或可组合区域，状态所有者保持稳定。普通 `loading`/`disabled` 不因此成为问题。重构保留焦点、键盘、可访问名称和原有保存行为。

## 共享包：复用还包括消费契约

宿主负责 API、权限和路由，组件包消费数据或约定的窄能力。多个宿主是否应共享组件，取决于语义、框架与维护节奏是否一致；React、Vue、SwiftUI、GPUI 项目可以共享治理方法，不因此需要同一个 UI 包。

先确认包声明的公共入口。未承诺稳定的 `package/src/...` 路径容易形成耦合；明确公开并受验证的子路径则是合法接口，不能为了“统一导出”强迫所有内容从巨大根入口加载。

本地源码、安装目录和锁定制品可能不同。跨包变更应以实际构建/打包产物做消费者验证，检查必要的 peer dependencies 和公开类型。开发 alias 下成功不代表制品可用；本地审查包也不代表已正式发布。

## 后端能力：复用规则，不复制提交流程

HTTP handler 处理协议输入输出，用例拥有业务操作顺序；具体数据库和网络访问沿已有端口与适配器接入。公共错误映射或只读查询可以提取，但不能把已有事务、快照发布、幂等或可靠写入拆成由每个页面自行拼装的“通用工具”。

单实现的端口若隔离真实外部系统或提供必要测试替身，已有价值；纯内部函数没有变化点时，不必先建接口和工厂。内存适配器可以验证规则，事务、重启和真实协议仍需相应验证。

## 看起来重复但应保留；看起来整齐但应合并

两个状态卡片外观相近，一个允许业务重试，另一个只能报告未知结果：可以共享布局与视觉语义，不能据此共享自动重试策略。不要通过大量配置抹平业务差异。

一个模块拆成许多只转发参数的小文件，理解和修改同一概念反而要来回跳转：可将紧密耦合的实现收回明确的所有者，保留少量必要接口。文件变短不是成功指标；变更局部性、调用复杂度和可验证行为才是。
